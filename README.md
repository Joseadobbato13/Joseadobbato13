## 🧭 Sobre mí

Ingeniero civil especializado en **automatización de flujos BIM** sobre Autodesk **Civil 3D 2026**.
Diseño herramientas que reducen el trabajo manual en el CAD: desde scripts **Dynamo** y plugins
**C# .NET** nativos, hasta un servidor **MCP** que permite operar Civil 3D **hablando en lenguaje
natural con IA (Claude)**.

- 🏗️ Redes de **saneamiento, drenaje e hidráulica** — de datos de cálculo a modelo 3D.
- 🤖 Puente **IA ↔ CAD**: Model Context Protocol conectado a la API COM/.NET de Civil 3D.
- 📐 **BIM / IFC 4.3**, alineaciones, corredores, estructuras y redes de tuberías.
